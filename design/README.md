# Макет «Ломбард онлайн» (этап 1)

Дизайн-макет восьми экранов в двух видах, построенных из **одного источника данных**:

- `illustrator/lombard-mockup.jsx` — сценарий Adobe Illustrator (ExtendScript), строит
  редактируемый документ с монтажными областями, слоями, глобальными образцами цвета
  и текстовыми стилями;
- `previews/*.png` (и `previews/svg/*.svg`) — превью тех же экранов, чтобы смотреть
  макет без Illustrator.

## Как открыть в Illustrator

1. Установите шрифты из `design/fonts/` (Spectral 300–600, Golos Text 400–700, лицензия OFL).
2. Если меняли экраны — пересоберите данные: `cd design && npm install && npm run layout`
   (готовый `layout/mockup.json` уже лежит в репозитории).
3. Illustrator → **File → Scripts → Other Script…** → `design/illustrator/lombard-mockup.jsx`.

Сценарий создаст документ RGB с 8 монтажными областями (сетка 4×2), отдельным слоем на
каждый экран, группой образцов «Ломбард онлайн» (глобальные цвета `lombard/<токен>` — смена
образца перекрашивает весь макет) и символьными/абзацными стилями `lombard/<стиль>`.
Стиль плоский: сценарий **не создаёт теней и живых эффектов** — только заливки и обводки,
поэтому документ одинаково выглядит в любой версии Illustrator. В конце — отчёт о числе
объектов и недостающих шрифтах.

## Как пересобрать превью

```bash
cd design
npm install
npm run build    # layout → mockup.json, svg → previews/svg, png → previews (Playwright, 2×)
npm run check    # проверка сценария Illustrator: ES3-синтаксис + прогон на мок-модели Illustrator
```

`node scripts/render-png.mjs --scale 1 landing` — быстрый рендер отдельных экранов в 1×.

## Устройство

```
design/
├── tokens.json                 # дизайн-токены — единый источник (позже → CSS-переменные, этап 9)
├── fonts/                      # Spectral, Golos Text (TTF, OFL)
├── layout/
│   ├── kit.mjs                 # примитивы и компоненты: кнопка, поле, бейдж, степпер, клеймо…
│   ├── content.mjs             # тексты лэндинга (общие для desktop и mobile)
│   ├── screens/01…08-*.mjs     # по файлу на артборд
│   ├── index.mjs               # порядок артбордов
│   └── mockup.json             # результат сборки — читают и SVG-генератор, и Illustrator
├── illustrator/lombard-mockup.jsx
├── scripts/
│   ├── build-layout.mjs        # screens → mockup.json
│   ├── build-svg.mjs           # mockup.json → previews/svg/*.svg
│   ├── render-png.mjs          # svg → png (Playwright)
│   └── check-jsx.mjs           # проверка сценария Illustrator
└── previews/
```

Экраны описываются в координатах артборда (px = pt, ось Y вниз) набором примитивов:
`rect`, `ellipse`, `path` (только ломаные — кривые аппроксимируются точками), `text`
(точечный текст, перенос строк считается заранее по метрикам настоящих шрифтов через
opentype.js) и `group`. Оба рендерера рисуют одно и то же; положение базовой линии
считается так же, как в CSS, поэтому фронтенд сможет повторить макет пиксель в пиксель.

## Концепция: «минимализм и точность»

Ломбард — это доверие к оценке и сохранность вещи. Доверие здесь передаётся не декором,
а ясностью: крупная сумма, понятные условия, ничего лишнего.

- **Плоские поверхности, без теней.** Глубина — только обводкой 1px (`line`), фон страниц —
  светлая бумага `paper #F2F4F0`, карточки — белые. Никаких гильошей, розеток, тёмных
  плашек и наложенных «листов».
- **Один акцент.** Малахит `malachite-700 #136150` — только для действий, активных
  состояний и прогресса. Текст и заголовки — графит `graphite-900`, второстепенное —
  `graphite-500`. Золото пробы (`gold-500/700`) встречается только в клейме пробы и в
  иллюстрациях металла. Цвета статусов несут смысл: синий — ждём, золотой — есть
  предложение, зелёный — деньги, красный — нужно внимание.
- **Шрифты.** Spectral (Production Type) — заголовки и суммы денег. Golos Text (Paratype) —
  интерфейс: гротеск, спроектированный для кириллицы и экранов. Оба поддерживают знак
  тенге ₸. Шкала: 68 / 48 / 36 / 22 / 19 / 16 / 14 / 13 / 12, суммы — стили `amount-xl/l/m`.
- **Главный образ** лэндинга — карточка предварительной оценки: фото, параметры, диапазон
  стоимости, уверенность и условия займа, разделённые тонкими линиями.
- **Клеймо пробы** — тонкий восьмиугольник с числом пробы; единственный фирменный элемент.
  Логотип — малахитовый квадрат с буквой «Л».
- **Небольшие радиусы:** поле 6, кнопка 8, карточка 12, бейдж статуса — пилюля.
- **Шаги и списки** — номерами `01–04` и линиями вместо кружков-иконок.
- **Сетка:** desktop 1440 — 12 колонок, контент 1200, поля 120, межколонник 24;
  mobile 375 — 4 колонки, поля 16, межколонник 12; базовый шаг 4.
- **Регион — Казахстан:** суммы в тенге (`95 200 ₸`, неразрывные пробелы), телефоны
  `+7 7XX XXX-XX-XX`, адреса Алматы.

Сквозной пример во всех экранах — одна заявка № 10-482 (кольцо, золото 585, 4,2 г):
предоценка 112 000 – 127 000 ₸, оценка эксперта 119 000 ₸, LTV 80 % → займ 95 200 ₸,
0,2 % в день на 30 дней → вернуть 100 912 ₸. На лэндинге — округлённый пример 95 000 ₸.
