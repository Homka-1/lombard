  загрузка), Field + Input (единица измерения) + Select + Checkbox + Segmented + Slider,
  Card + KeyValue, Badge/StatusBadge/Chip/Spinner/Alert, Stepper, Modal (нативный `<dialog>`),
  Toast (провайдер, автоскрытие с паузой при наведении), Uploader (drag&drop, превью,

## Как проверить
```bash
cd backend && alembic upgrade head && python -m app.seed && uvicorn app.main:app --reload
cd frontend && npm install && npm run dev          # http://localhost:5173
cd frontend && npm test && npm run lint && npm run format:check && npm run design:check && npm run build
```
В браузере: калькулятор на главной пересчитывает сумму; «Войти» → карточка «Клиент» → «Войти»
→ кабинет клиента; меню пользователя → «Выйти».

## Принятые решения
- **Генерация, а не копирование токенов**: CSS-переменные и иконки — артефакты сборки из
  `design/` (коммитятся, чтобы фронтенд и будущий `demo/` не зависели от зависимостей макета).
- **Пример в герое — статичный** (сквозная заявка макета), но числа согласованы с реальной
  ставкой золота 0,25 %/день: 95 000 ₸ × 30 дней → 102 125 ₸. Живые числа — в калькуляторе.
- **Навигация кабинета — общая шапка для всех ролей**; сайдбар админа из артборда 8 и
  мобильная шапка курьера — на этапе 11 вместе с их экранами.
- **Токены доступа в `localStorage`** (учебный проект; для прода — httpOnly-cookie refresh).
- Выход — переход на главную и сброс сессии в одном `startTransition`, иначе `RequireRole`
  успевает отправить гостя на страницу входа (флаг React Router `v7_startTransition`).
- В Segmented/формах — нативные `input type=radio/range`, `<dialog>`, `<details>`: клавиатура и
  скринридеры работают без собственного кода.

## Известные проблемы и техдолг
- Страницы «витрины» компонентов (артборд 1) нет — компоненты проверяются тестами и в
  кабинетах этапов 10–11.
- Ссылки подвала «О ломбарде», «Документы», «Тарифы» из макета не добавлены — страниц нет.
- Шрифты подключены со всеми подмножествами `@fontsource` (браузер скачивает только нужные
  по `unicode-range`, но в `dist` лежат и latin-ext/vietnamese).
- Uploader не сжимает фото перед отправкой; ограничения дублируют настройки backend
  (`LOMBARD_MAX_PHOTOS`, `LOMBARD_MAX_PHOTO_MB`) константами.
- Нет страницы профиля и смены пароля (API есть: `PATCH /api/auth/me`, `POST /api/auth/me/password`).
