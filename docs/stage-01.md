## Как проверить
```bash
cd design
npm install
npm run build   # mockup.json → svg → png
npm run check   # ES3 + прогон сценария Illustrator на мок-модели
```
В Illustrator: установить шрифты из `design/fonts/`, File → Scripts → Other Script… →
`design/illustrator/lombard-mockup.jsx`.

## Принятые решения
- Малахит + золото пробы + холодная «банкнотная» бумага вместо типовых сочетаний;
  золото только для металла/клейма/фокуса. Spectral (суммы, заголовки) + Golos Text (UI).
- Фирменный образ — залоговый билет с гильошем и линией отрыва; клеймо пробы — знак
  оценки и основа логотипа. Радиусы растут с иерархией (6/10/16/24/пилюля).
- Примитивы ограничены тем, что умеют оба рендерера: без градиентов, масок и кривых Безье
  (кривые — ломаными), текст — точечный с заранее рассчитанным переносом.
- Базовая линия текста считается как в CSS (half-leading) — фронтенд повторит макет.
- Глобальные spot-образцы в Illustrator: правка токена-образца перекрашивает весь макет.
- Сквозная демо-заявка № 10-482 с согласованными числами на всех экранах
  (119 000 ₸ × 80 % = 95 200 ₸; 0,2 %/день × 30 дней → 100 912 ₸).

## Известные проблемы и техдолг
- Сценарий не проверен в живом Illustrator; эффект Drop Shadow задаётся через
  недокументированный XML живого эффекта (обёрнут в try/catch).
- Шрифты в репозитории — TTF целиком (~0,9 МБ); для веба на этапе 9 лучше подключить
  woff2-подмножества (например, `@fontsource/spectral`, `@fontsource/golos-text`).
- Не нарисованы: экраны займа/залогового билета клиента, осмотр экспертом, модалки —
  делать по аналогии с дизайн-системой на этапах 10–11.
