# Ломбард онлайн — демо без зависимостей

Откройте **`index.html`** двойным щелчком. Ничего устанавливать не нужно: ни Python, ни
Node.js, ни сервер, ни интернет. Страница работает прямо с диска (`file://`) в современном
браузере; автотесты гоняются в Chromium.

## Как показывать

| Где | Что |
|-----|-----|
| Тёмная панель сверху → **Клиент / Эксперт / Курьер / Админ** | Вход за демо-аккаунт одной кнопкой. Обычный вход тоже работает: `client@lombard.kz`, `expert@…`, `courier@…`, `admin@…`, пароль `demo1234` |
| **+1 день**, **+7 дней** | Перемотка времени: продление, просрочка, через 30 дней льготного периода — изделие переходит ломбарду. **Вернуть сегодня** — обратно |
| **Сбросить демо** (второй щелчок подтверждает) | Стереть всё, что сделано, и вернуть исходные данные |

На телефоне время и сброс открываются кнопкой **Демо ▾**.

Полный путь одной вкладкой:

1. **Клиент** → «Новая заявка»: золото, проба 585, вес, состояние, 1–6 фото → «Отправить на
   оценку» — предоценка с диапазоном и уверенностью.
2. **Эксперт** → заявка в очереди → «Взять в работу» → рыночная стоимость → «Отправить
   предложение». (Заявка Данияра Ахметова с фото ждёт эксперта с самого начала.)
3. **Клиент** → «Принять и вызвать курьера» → адрес и время.
4. **Курьер** → «Выехал к клиенту» → «Изделие у меня» → «Доставил в ломбард».
5. **Эксперт** → «Осмотр» → «Подтвердить осмотр».
6. **Клиент** → карта `4400 4301 2345 6789` → «Получить …» (карта `4000 0000 0000 0002` —
   отказ банка) → залоговый билет, продление, погашение.
7. **+7 дней** / **+1 день** — займ просрочен; погасить → вызвать курьера для возврата.
8. **Курьер** → «Выехал с изделием» → «Передал клиенту». **Админ** — дашборд, справочники,
   пользователи, назначение курьеров.

## Как устроено

| Файл | Что это |
|------|---------|
| `index.html` | Страница: обычные `<script src>` — без ES-модулей и без загрузки файлов через `fetch` |
| `js/app.js` | Тот же интерфейс, что в `frontend/` (React), собранный в один скрипт. Маршрут хранится после `#` |
| `js/mock-api.js` | Мок-бэкенд: перехватывает запросы `/api/…` и отвечает так же, как backend — машина состояний заявки, предоценка, анализ фото, калькулятор займа, слоты курьеров, займ, продление, просрочка, мок-банк, уведомления, статистика |
| `js/seed-photos.js` | Фото для демо-заявки |
| `css/app.css`, `fonts/` | Стили (CSS-переменные из `design/tokens.json`) и шрифты Spectral, Golos Text |

Данные хранятся в `localStorage` этого браузера: они переживают перезагрузку, но не видны в
другом браузере. Фото уменьшаются до 1280 px; если место в хранилище (около 5 МБ)
закончится, демо попросит удалить черновики или сбросить данные.

Отличия от настоящего backend: пароли не шифруются (это демо), токены не истекают, анализ фото
считается на `<canvas>` вместо Pillow — те же метрики, но цифры качества могут немного
отличаться. Формулы предоценки и займа совпадают с backend один к одному (это проверяет
тест `frontend/src/demo/mockApi.test.ts`).

## Пересборка

Папку не нужно править руками — она собирается из исходников фронтенда:

```bash
cd frontend && npm run build:demo   # пересобрать
cd frontend && npm run demo:check   # совпадает ли demo/ с исходниками
cd frontend && npm run e2e:demo     # Playwright: весь сценарий по file://
```

Исходники демо-части: `frontend/demo-src/` (мок-API и шаблон страницы),
`frontend/src/demo/` (панель демо-режима), `frontend/scripts/build-demo.mjs` (сборка).
